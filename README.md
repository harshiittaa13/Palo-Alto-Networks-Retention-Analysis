# Career Progression and Promotion Gap Analysis - Palo Alto Networks

## Objective
To analyze promotion gaps and reduce employee attrition.

## Dataset
Employee data with Gender, Department, Performance, Promotion status

## Key Insights
- Female promotion rate is lower than Male (25% vs 35%)
- Employees with 3+ years, high performance but no promotion have high attrition risk
- Engineering department needs attention

## Tools Used
Excel / Power BI / Python

## Recommendations
1. Make promotion criteria transparent
2. Start mentorship program
3. Regular career growth review
